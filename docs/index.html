为隐私与原生体验而设计

全部建立在 macOS 原生框架与加密磁盘能力之上，不安装任何第三方驱动。

AES-256 APFS 稀疏加密卷

容量随实际写入动态增长，支持解锁态实时查看卷内占用；删除分身或还原应用后，锁定时后台自动压缩回收宿主机磁盘空间。

Finder / Spotlight / Launchpad 三重隐身

挂载时采用私有隐藏目录并禁用 Spotlight 索引，移入应用时自动注销系统 LaunchServices 缓存，从启动台彻底隐身。

保留原应用的加密分身

完整保留原版 Apple 开发者签名复制到加密卷，分配独立卷内 HOME 目录并按进程 PID 精准追踪，支持与宿主机原应用双开运行。

Touch ID 与全场景自动重锁

支持系统硬件钥匙串指纹解锁与主密码管道直通；目标应用退出、AppVault 退出、休眠锁屏、空闲超时与快捷键急锁全自动触发。

多层安全与防篡改加固

内置密码错误持久化退避锁、路径穿越校验、提权路径白名单、运行时反调试与防注入自检、以及自身代码签名完整性校验。

原生 SwiftUI × shadcn/ui 体验

极简浅/深色主题一键切换且与系统顶栏无缝同色；菜单栏常驻快捷启停，关闭主窗口自动隐藏 Dock 图标，支持登录自启与一键定位备份。

两种收容模式对比

按实际使用场景灵活选择「移入隐藏」或「创建加密分身」。

对比维度 移入隐藏（原位移除） 创建分身（保留原应用）
原位 /Applications/*.app 移入加密卷并注销 Launchpad / Spotlight 保留在原位完全不受影响
数据隔离机制 迁入 ~/Library 数据，解锁时事务化软链桥接，锁定即撤链 加密卷内独立隔离 HOME 目录，宿主机零污染
适用应用范围 第三方非沙盒独立应用 非沙盒与沙盒应用均支持（保留原版签名，不触发重签名闪退）
与原应用同时双开 不适用（原应用已隐藏） 支持（独立进程实例 + 精确 PID 追踪）
移出 / 清理方式 「还原」完整迁回 /Applications 与 ~/Library 并恢复索引 「删除分身」仅移除卷内副本与数据，锁定后自动压缩回收磁盘

全生命周期安全闭环

宿主机明文配置绝不记录受管应用列表，应用清单仅存于加密卷内部。

STEP 01

锁定静默态

加密容器隐藏存储，无挂载点、无软链残留、无 Spotlight 索引。

STEP 02

认证与私有挂载

通过运行时自检与 Touch ID / 主密码验证后，经管道挂载至私有隐藏目录。

STEP 03

隔离运行与监听

按精确 PID 追踪受管进程与分身实例，同时订阅休眠、锁屏、空闲与急锁快捷键。

STEP 04

退出重锁与回收

目标应用或 AppVault 退出时自动撤链、安全卸载加密卷，并自动压缩回收空间。

下载与安装

下载预编译 DMG 拖入 Applications 即可使用；或通过 Swift Package Manager 从源码构建。

方式一：下载预编译 DMG

前往仓库 Releases 页面下载 AppVault-macOS-arm64.dmg，打开后将 AppVault.app 拖入 /Applications。首次运行若系统提示未公证开发者，请前往「系统设置 → 隐私与安全性」点击「仍要打开」。

方式二：从源码编译

需要 macOS 14+ 与 Swift 5.9+（仅需 Command Line Tools，无需完整 Xcode）：

./Scripts/package_app.sh && open dist/AppVault.app
